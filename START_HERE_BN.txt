AI PhotoShop — শুরু করার আগে এই লেখাটি পড়ুন

এটি Android অ্যাপের সোর্স প্রজেক্ট ZIP; এটি এখনো ইনস্টল করার APK ফাইল নয়।

আপনি যদি GitHub মোবাইল পেজে থাকেন:
1) ZIP ফাইলটি ডাউনলোড করে Extract/Unzip করুন।
2) GitHub-এর “choose your files” জায়গায় ZIP ফাইল আপলোড করলেই অ্যাপ তৈরি হবে না—GitHub-এ প্রজেক্টের ভেতরের ফাইলগুলো আপলোড করতে হয়।
3) শুধু মোবাইল দিয়ে ফোল্ডারসহ সব ফাইল ঠিকমতো আপলোড করা জটিল হতে পারে।
4) আপলোড হলে GitHub → Actions → “Build AI PhotoShop APK” → Run workflow চালাতে হবে।
5) Build সফল হলে Actions-এর কাজের পাতার Artifacts অংশ থেকে “AI-PhotoShop-debug-APK” ডাউনলোড করতে হবে। ZIP-এর ভিতরে APK আগে থেকে নেই।

এই প্রজেক্টটি এখনো এখানে APK হিসেবে কম্পাইল/পরীক্ষা করা হয়নি।
